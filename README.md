# Learn-English-Patterns

**English Patterns — تعلّم الإنجليزية بالأنماط.** تطبيق Node.js مستقل، مع الصور والتسجيلات والترجمات وتوقيت الكلمات داخل هذا المجلد.

```text
node server.js
```

ثم افتح http://127.0.0.1:4180 . يمكنك أيضًا `npm start`. يحتاج التشغيل Node22 أو أحدث، ولا يحتاج تثبيت مكتبات npm أو Python أو تنزيل نماذج. في Windows يمكن تشغيل `Start-English-Patterns.cmd`.

ابدأ الاستكمال من **[HANDOFF.md](HANDOFF.md)**، ثم [قائمة النواقص](docs/COMPLETION-BACKLOG.md) و[حالة الفحص](docs/VERIFIED-STATUS.json).

تغطية الإنتاج الحالية والنسب حسب المرحلة: [PRODUCTION-STATUS.json](docs/PRODUCTION-STATUS.json). توجيه جميع الصور الجديدة: [سياسة المشاهد المناسبة للثقافة العربية والإسلامية](production/scene-policy.json).

الواجهة بالعربية أو الإنجليزية، مع إظهار/إخفاء العربية، وإبراز الأنماط بالأحمر، ووقفات قراءة بمؤشر تقدم، وبحث وفلاتر وصفوف/بطاقات. تتوفر إضافة نمط شخصي ونسخ التقدم، وتنزيل المحتوى بصوتيه وصوره وتثبيتPWAعند دعم المتصفح عبرHTTPSأوlocalhost. تُحدّث الواجهة تلقائيًا مع حفظ الموضع والوسائط الصالحة. [التفاصيل](docs/INTERFACE-AND-OFFLINE.md).

بعد تعديل ملفات الواجهة أو المحتوى شغّل `npm run build` ثم `npm run check`. لا يحتاج البناء أي مكتبات إضافية أوPython؛ لا تثبّت نماذج أو بيئاتPythonداخل المشروع.

- main: تطبيق Node وملفات public والمحتوى والخطط والوثائق والاختبارات.
- media-tools: أدوات إنتاج الصوت ومعالجة الصور الصغيرة. ينزل GitHub مكتباتها على خوادمه؛ ليست متطلبات لتشغيل التطبيق.
- production/run-ID: نتائج صوت متحققة ومحفوظة قبل دمجها إلى main.
- handoff/media-tools.bundle: نسخة صغيرة لاسترجاع فرع الأدوات إذا نُقل المجلد دون تاريخه.

تظهر صور الجمل في مكتبة الألف جملة وفي مشغّل الاستماع، مع خيارات **كاملة / مصغّرة / مخفية** تحفظ تلقائيًا. الصور المرفوضة أو غير المكتملة لا تُعرض كصور معتمدة.

لا تحذف المشروع السابق قبل نقل هذا المجلد كاملًا إلى مكان مستقل وتشغيله منه. احتفظ بـ.git أو بملف handoff/media-tools.bundle. نقل الملفات لا ينقل localStorage بين عناوين الخادم؛ من صفحة الملفات صدّر التقدم واستعده عند الحاجة.
