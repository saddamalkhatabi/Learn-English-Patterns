# إضافة أطالس WebP الجاهزة

الدفعة الأولى `new_images_pattern_1_a.zip` في `public/assets/scenes/` تحتوي 30 أطلسًا للمهام EP-IMG-001 إلى EP-IMG-003. الأسماء مطابقة والفكّ تم. كل ملف 1536×2048، شبكة 3 أعمدة × 4 صفوف. كاشف الفواصل قاس 29 أطلسًا؛ `pattern-9070` يستخدم قصًا داخليًا احتياطيًا لأن فواصله البيضاء ليست متصلة على امتداد الصف كله.

إضافة الدفعة التالية: ضع ملفات WebP النهائية مباشرة في `public/assets/scenes/` بأسماء مثل `pattern-9072-atlas-v1.webp`، أو ارفع ZIP لا يزيد عن 20 MiB يحتوي الملفات في الجذر بلا مجلدات. كل أطلس 1536×2048، 12 مشهدًا مربّعًا بترتيب الصفوف من اليسار إلى اليمين. يجوز أن يكون اسم الأرشيف `new_images_pattern_2_a.zip`؛ الأسماء الداخلية وحدها تحدد الأنماط. لا تضع ملفات PNG داخل هذا المسار البديل؛ استخدم مسار المراجعة الأصلي لملفات PNG وتقارير الخلايا.

عند رفع ZIP أو WebP إلى `main`، يشغّل GitHub Action `Unpack and connect WebP scene atlases` الفكّ الآمن، وقياس القصّ، و`npm run build` و`npm run check` ثم يحفظ الفهارس والملفات المفكوكة في `main`. يمكن تشغيله يدويًا أيضًا. محليًا:

```powershell
python scripts/unpack-webp-atlases.py public/assets/scenes/new_images_pattern_2_a.zip
npm run build
npm run check
```

إذا وضعت WebP مباشرة دون ZIP، يكفي `npm run build` ثم `npm run check`؛ يأخذ البناء قصًا داخليًا محافظًا إذا لم تتوفر قياسات خاصة. الصور تظهر في «استكشف الأنماط» مع الجمل والترجمة وصوتي الذكر والأنثى. جميع الأمثلة المؤلفة الـ1836 قابلة للاستماع الآن، حتى عندما لا تصل صورها بعد.

**حالة المراجعة:** صور WebP الجديدة موسومة `imported-unreviewed`، وهذا يعني أنها قابلة للتجربة وليست معتمدة بصريًا بعد. `pattern-9071-02` محجوبة لأن القميص الرياضي قصير الأكمام. لتصحيح أطلس سبق استيراده، أرسل نسخة جديدة باسم `pattern-9071-atlas-v2.webp` بعد إعادة توليد المشهد المخالف، ثم راجعها واحذف الحجب من `production/qa/scene-holds.json` عند قبولها. لا تستبدل ملفًا معتمدًا بالاسم نفسه. النشر الكامل للدروس المتدرجة والاختبار السمعي البشري لهما حالة مستقلة عن توفر النص والصوت والصورة في مستكشف الأنماط.
