# واجهة القراءة والاستماع والعمل دون إنترنت

تحديث2026-11-03. التطبيق مستقل، ويحتاج Node22 فقط لتشغيله. لم تُضف تبعيات npm أو مكتبات Python أو نماذج محلية. أدوات الصور الصغيرة موجودة فيmedia-tools وتستخدمFFmpeg؛ توليد الصوت يعمل علىGitHub. أزيلت نسخ استيراد مؤقتة انتهى استخدامها، وبقيت الملفات الفعلية المطلوبة للمشروع ومصادر الصور المعتمدة.

## العرض والتعلّم

- الشعار: بنية حمراء متكررة وكلمات متغيرة داخل رمز حوار؛ SVG للواجهة وPNG بأبعادي192و512للتثبيت.
- الجملة الحالية وصورتها وترجمتها متجاورة في درس الحاسوب، ومتتابعة بحجم مضبوط على الهاتف. لا يستمر إخفاء نص مثال جديد بسبب إخفاء المثال السابق.
- كل المشاهد داخل إطارات مربعة ثابتة؛ تعرض الخلية المقاسة كاملة بنسبة أبعادها الأصلية، مع هوامش عند الحاجة، دون تمديدها أو قص دلالتها. يبقى قص الأطلس نفسه بحسب الإحداثيات المسجلة.
- القواعد والأجزاء الثابتة بالأحمر؛ تمييز الكلمة المنطوقة مستقل. `teaching-index.json` يربط المعرفات بإرشاد عربي وإنجليزي وغرض وملاحظة استعمال وتحديد كلمات البناء. ليست هذه درجات آلية لصحة اللغة أو المعنى.
- الوقفات بين الأنماط تعرض القاعدة والفرق المهم وعداد القراءة. الافتراضي25ثانية، ويمكن اختيار15/25/40/60وزيادة10ثوانٍ أثناء الوقفة. الإيقاف المؤقت يحفظ الباقي؛ زر المتابعة ينتظر انتهاء القراءة. يبقى خيار الانتقال التلقائي مستقلًا.

## اللغة والفلترة

لغة الواجهةar/en مستقلة عن إظهار الترجمة والشروح العربية. التفضيل محفوظ باسم`patterns-preferences`. الشروح الإنجليزية تبقى ظاهرة عند إخفاء العربية. الترجمة لا تغيّر جمل المصدر أو إجابات الاختبارات الداخلية.

مكتبة الجمل تدعم البحث عن جميع كلمات الاستعلام، والفلترة المركبة بالبناء والموقف والغرض والمستوى وحالة الصورة، والفرز، وحجم الصفحة، والبطاقات/الصفوف. تحفظ خياراتها في`patterns-reference-view`. استكشاف الأنماط يميز الدروس المتاحة عن الإنتاج، ويتيح حفظ نمط شخصي محليًا؛ لا يُحتسب النمط الشخصي درسًا منشورًا أو تسجيلًا مولدًا.

لم تُضفSQLite/KnexأوDataTables: المحتوى ثابت وحجمه مناسب لفهرسة المتصفح، والعمل دون إنترنت يحتاج البيانات محليًا. البيانات الأساسيةJSON، والتفضيلات والتقدم والأنماط الشخصية فيlocalStorage، والوسائط فيCache Storage. قرار قاعدة بيانات خادم يصبح ذا معنى عند اعتماد حسابات أو مزامنة متعددة الأجهزة؛ هذه الميزات لم تُدّعَ هنا.

## التنزيل والتحديث

`offline-manifest.json` يسرد الملفات الفعلية وبصماتها وأحجامها ومجموعاتها: الدروس والقصص، أوالألف جملة، أوكل الوسائط المنتجة بما فيها التوسعة. لا تدخل الصور المحجوبة للمراجعة إلى التنزيل. التوسعة المنتجة لا تتحول إلى درس منشور بمجرد تنزيلها.

تُخزن الوسائط الكاملة عند فتحها، وتحفظ تسجيلات الصوتين للمشاهد المفتوحة. زر التنزيل يعرض الحجم والعدد والتقدم والإلغاء، ويتحقق من المساحة المتاحة، ويحتفظ بالنجاح الجزئي لإعادة الاستكمال. لا يعلن الاكتمال إذا أخفق أي ملف. قد يزيل المتصفح التخزين تحت ضغط المساحة؛ طلب الاستبقاء لا يضمن موافقة الجهاز.

يعيد العامل الأجزاء الصحيحة206/416منMP3الكامل لدعم التقديم والتأخير دون شبكة؛ لا يخزن استجابة جزئية على أنها الملف كله. كل ملف محفوظ مرتبط ببصمته. كاش الوسائط مستقل عن نسخة الواجهة، فلا يُحذف عند تحديثها.

يتحقق التسجيل من العامل عند الفتح والعودة إلى النافذة والاتصال، وكل دقيقة أثناء فتح التطبيق. عند تفعيل إصدار جديد يُحفظ موضع المشغّلين والتقدم، ثم يعاد تحميل الواجهة تلقائيًا. يحتاج تثبيتPWAوالعاملHTTPSأوlocalhost؛ ظهور نافذة التثبيت يعتمد على المتصفح، مع إرشادات تثبيت يدوية عند عدم دعمها.

قبل رفع أي تغيير في الواجهة أو المحتوى:

```text
npm run build
npm run check
```

البناء يحدّث الإرشاد وفهرس التنزيل ومعرف إصدار مشتق من المحتوى. اختبار البصمات يمنع رفع نسخة عامل قديمة لا تكتشف التعديلات. لا يتطلب البناء Python أو تنزيل أي مكتبات أو نماذج.
